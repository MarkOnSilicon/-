# 全球媒体观察 Global Media Watch

一个面向手机使用的全球新闻监测与比较分析应用。

帮助用户快速了解：主要国家的主流媒体正在关注什么，以及不同媒体如何报道同一事件。

> 项目处于规划阶段。以下内容描述开发目标，不代表功能已经实现。

## 产品目标

减少跨语言、跨媒体阅读新闻的时间，同时保留原始来源，帮助用户形成自己的判断。

产品重点回答两个问题：

1. **关注差异：**同一时间段，不同国家的所选媒体分别把哪些事件放在重要位置？
2. **报道差异：**对于同一事件，不同媒体在事实陈述、标题措辞、报道重点和引用对象上有哪些异同？

本项目首先监测新闻媒体报道。分析结果代表所选媒体样本，不直接代表所在国家的政府立场或公众意见。

## 核心功能

### 全球头条

- 按国家、媒体、主题和时间浏览新闻。
- 同时展示原标题与中文翻译。
- 显示来源、发布时间、采集时间和原文链接。
- 区分首页头条、栏目推荐与订阅源最新新闻。
- 记录头条位置变化，观察媒体关注重点的变化。

### 同一事件对比

- 将不同语言、不同媒体对同一事件的报道归为一组。
- 对比共同提及的信息、事实分歧、报道重点、标题措辞和引用对象。
- 为分析结论提供对应报道及相关片段。
- 区分原文信息与 AI 分析，标注证据不足和不确定之处。

### 每日简报

- 汇总当日所选媒体共同关注的主要事件。
- 展示不同国家媒体样本之间的关注差异。
- 支持收藏事件、跟踪主题和查看后续报道。

## 首版范围

先验证少量媒体的数据质量，再逐步扩大覆盖：

- 选择 3 个国家，每国 2—3 家媒体。
- 以中文阅读为主，保留原文。
- 优先覆盖国际事务、经济和科技。
- 提供头条列表、事件对比与每日简报。
- 优先开发适配手机、可添加到主屏幕的网页应用。
- 具体国家、媒体名单和更新频率在数据源验证后确定。

长期目标是覆盖更多主要国家，并按需开发独立手机应用。

## 数据与分析原则

- 优先使用媒体官方 RSS、开放接口和取得相应使用权限的数据源。
- 记录媒体所属国家、报道语言和页面版本，区分本土版与国际版。
- 识别重复文章与通讯社转载，避免重复计算独立来源。
- 在相近时间窗口内比较报道，减少事件进展造成的误判。
- 只有标题时，仅分析标题；没有正文依据时，不生成正文层面的结论。
- 多家媒体重复提及，不自动视为事实已经得到独立证实。
- “未发现报道”仅指当前样本和采集时间范围，不推断媒体刻意隐瞒。
- 数据源失败或更新中断时明确提示，不把缺失数据解释为没有新闻。
- 按来源许可使用内容，展示必要摘要、证据片段及原文链接。

## 开发顺序

- [ ] 确定首批国家和媒体名单。
- [ ] 验证数据源可用性、使用权限与内容完整程度。
- [ ] 连续采集 3 天，检查头条识别、重复文章和时间信息。
- [ ] 实现跨语言事件归类。
- [ ] 实现带来源依据的报道对比。
- [ ] 完成手机端页面与每日简报。
- [ ] 部署试用，评估准确性、稳定性和运行费用。

## 首版验收标准

- 手机可以正常浏览新闻和事件对比。
- 每条新闻可追溯到来源与原文。
- 每条分析结论有对应证据，或明确标注证据不足。
- 清楚区分首页头条与最新新闻。
- 清楚显示数据更新时间及采集异常。
- 人工抽查事件归类和比较结果，记录并修正错误。
